# Preprocessing

## Objective

The purpose of preprocessing is to prepare the Netflix Customer Churn Dataset for machine learning modelling by improving data quality and ensuring all variables can be used effectively by prediction algorithms.

## Preprocessing Techniques

The following preprocessing techniques will be applied:

1. Missing value identification and treatment.
2. Removal of duplicate records.
3. Data type correction.
4. Encoding categorical variables using Label Encoding or One-Hot Encoding.
5. Scaling numerical variables using StandardScaler.
6. Train-test split using an 80:20 ratio.

## Related Script

preprocessing.ipynb

## How to Run

Open preprocessing.ipynb in Jupyter Notebook and execute all cells from top to bottom.

## Output

The notebook produces a cleaned dataset that will be used during feature engineering and model training.
