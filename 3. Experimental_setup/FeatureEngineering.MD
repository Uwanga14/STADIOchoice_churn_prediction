# Feature Engineering

## Objective

The objective of feature engineering is to create meaningful variables that improve churn prediction performance.

## Feature Engineering Techniques

The following features will be created where applicable:

1. Customer tenure groups.
2. Subscription value categories.
3. High engagement and low engagement indicators.
4. Average viewing activity indicators.
5. Customer activity frequency measures.
6. Churn-related behavioural indicators.
